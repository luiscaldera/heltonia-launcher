# Heltonia Launcher - config backup

Public backup of the Heltonia Launcher configuration (`config.json`), served by GitHub Pages at
https://luiscaldera.github.io/heltonia-launcher/config.json

The launcher reads https://heltonia.com/launcher/config.json first and uses this copy only if the main server is
unreachable. It only contains public URLs, versions and news. Updated by `tools/publish_launcher.py`.
